# Карта в голове

Интерактивный курс по географии: 6 уроков, карточки, тесты, флаги, тренажёр.
Работает офлайн и ставится на главный экран телефона как приложение.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `karta`.
2. Нажмите **Add file → Upload files** и перетащите **содержимое** этой папки
   (`index.html`, `manifest.webmanifest`, `sw.js`, папку `icons`) — не саму папку.
3. **Commit changes**.
4. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*,
   Branch — `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/karta/`.

## Как добавить значок на главный экран

- **iPhone:** откройте ссылку в Safari → кнопка «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Прогресс сохраняется в браузере на устройстве (localStorage).
После обновления файлов на GitHub приложение подтянет новую версию при следующем запуске с интернетом.
